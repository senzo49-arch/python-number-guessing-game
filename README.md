# Python Number Guessing Game
 simple **Number Guessing Game** built with Python.
This is a beginner project created to practice fundamental Python concepts, especially **variables, user input, conditions, and while loops**.

# How It Works
The program has a secret number, and the user tries to guess it.
* If the guess is too low, the program says **"Too low!"**
* If the guess is too high, the program says **"Too high!"**
* When the user guesses correctly, the game ends.

# text
Guess a number from 1 to 10: 3
Too low!

Try again: 8
Too high!

Try again: 7
Correct! You won!
